## Built_in commands : 
Liste des commandes que l'on doit implementer dans minishell

* **echo** with option -n
* **cd** with only a relative or absolute path
* **pwd** with no options
* **export** with no options
* **unset** with no options
* **env** with no options or arguments
* **exit** with no options

**Exemples :**
```c
[minishell] > echo "Hello World" > outfile //creation d'un file "outfile" avec "Hello World" dedans
[minishell] > echo "Hello" World
Hello World
```
